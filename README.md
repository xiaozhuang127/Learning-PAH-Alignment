# Learning-PAH-Alignment-for-UDA-SAR-Target-Recognition-Using-Simulated-Data
This is the code repository address for the paper "Learning Prototype-Archetype-Hypersphere Alignment for Unsupervised Domain Adaptation SAR Target Recognition Using Simulated Data". First, you can follow the method proposed by Alcacer et al. (Biarchetype Analysis: Simultaneous Learning of Observations and Features Based on Extremes. IEEE Transactions on Pattern Analysis and Machine Intelligence) to calculate the archetypes. Then, you can construct a geometric hypersphere in the embedding space based on the archetypes and prototypes. Second, you can run the main.py script. More details will be updated in due course.

## Install
`pip install -r requirements.txt`
The code is written in Python 3.12.12, but should work for other versions with some modifications.
